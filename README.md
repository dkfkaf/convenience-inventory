# 편의점 재고 손실 예측 및 프로모션 의사결정 지원

단일 편의점의 재고·판매·폐기 기록을 관리하고, 소비기한과 판매 추세로 재고 위험을 확인하는 Team 4 프로젝트예요. 정상 판매·1+1·2+1의 개당 이익을 비교해 점포 관리자가 검토할 행사를 고르는 데 도움을 줘요.

## 주요 기능

- **상품·재고·판매 관리** — 상품과 소비기한별 재고로트를 등록하고, 판매 시 기한이 빠른 재고부터 차감해요.
- **재고 위험 조기경보** — 소비기한 임박·경과, 예상 폐기 위험, 장기 미판매를 구분해 보여줘요.
- **프로모션 수익성 비교** — 정상 판매·1+1·2+1의 개당 매출총이익과 구성 가능 수량을 비교해요.
- **폐기·재고변동이력 관리** — 폐기 수량과 사유, 재고 증감, 당시 로트 원가로 계산한 실제 폐기 손실을 확인해요.

개발 범위는 단일 점포의 재고 관리와 행사 검토까지예요. 행사 적용·승인, POS 실시간 연동, 발주·출고, 머신러닝 예측은 명세의 제외 범위를 따라요.

## 실행과 테스트

백엔드 의존성과 MySQL 스키마가 준비되면 저장소 루트에서 다음 명령을 실행해요. 테스트에는 개발·시연용 DB와 구분한 테스트 전용 스키마를 사용해요. DB 설정과 시연 실행 절차는 [실행·검수 가이드](test/quickstart.md)에 있어요.

```powershell
python -m pip install -r backend/requirements.txt -r test/requirements-dev.txt
python -m pytest -v test
```

[GitHub Actions 워크플로](.github/workflows/tests.yml)는 `main` 대상 PR에서 MySQL 8.4와 전체 pytest를 실행해요.
